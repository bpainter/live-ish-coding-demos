# Governance

## Model

One named maintainer decides. The maintainer is the owner of this repository, and the repository page shows who that is. There is no committee, and this file does not pretend to one.

## Scope

A feature must serve a talk where the demo is the point. "No" is a normal, kind answer here. The [limits page](docs/content/limits.mdx) says what Live-ish does not try to do.

## Response

Best effort. The target for triage is 7 days. There is no promise on fixes.

No bot closes an issue because of its age.

## Bus factor

The target is a second npm owner and a second GitHub admin. Until that person exists, a written succession note and a recovery kit for the npm scope stay with the maintainer.

## Contributors to maintainers

After sustained, reviewed work, the maintainer offers triage rights first. Commit rights can follow.

## Funding

None at launch. The project will look at this again after v1.0.
