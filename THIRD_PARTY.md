## Fonts

Each family sits in `packages/engine/assets/fonts/<family>/` with its `OFL.txt`. The table is read from the files themselves: run `pnpm --filter @live-ish/engine fonts:licenses` to print it. A deck receives only the families its themes use.

All five are under the SIL Open Font License 1.1. No file's name table or `OFL.txt` declares a Reserved Font Name.

**Why Atkinson Hyperlegible is not subset.** The release we ship declares no Reserved Font Name. Earlier licensing of this family by its publisher has been described with reserved names, which we could not confirm or rule out from the files. A subset is a Modified Version under the OFL, so if a reserved name did apply, a subset could not keep the name. Shipping the full, unmodified face avoids the question, at a cost of about 12 KB on a page. It still fits the 60 KB budget.

**JetBrains Mono** is also a trademark of JetBrains s.r.o. The OFL covers the font software, not the mark. We use the name only to say which font this is.

The four subset families declare no Reserved Font Name, so the OFL lets a Modified Version keep its name. The subsetting used fontTools (`pyftsubset` options: `--flavor=woff2 --no-hinting --layout-features=kern,liga,ccmp,locl,mark,mkmk`, without `liga` for JetBrains Mono). Each file keeps its copyright and license name records.

`early-web` uses system fonts and ships no file.
