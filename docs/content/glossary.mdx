---
title: Glossary
outcome: When you finish this page, you will know what each word in these docs means.
---

| Word            | What it means                                                                                                                                                              |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Audience window | What the room sees on the projector, at `/present`.                                                                                                                        |
| Beat            | One part of a demo's story: `intro`, `before` or `after`. Each beat is one page in the deck.                                                                               |
| Chrome          | What an audience theme draws around a demo: the backdrop, the cards, the code panel and the spotlight. Its tokens start with `--chrome-*`. It is unrelated to the browser. |
| Clicker         | The handheld remote that sends the arrow keys, Page Up and Page Down, or Space.                                                                                            |
| Copy slide      | A slide of text and images. See [copy slides](/copy-slides).                                                                                                               |
| Demo            | One folder under `demos/`, with its script, its files and its steps.                                                                                                       |
| Digest          | A record of a page's state after a step: its address, focus, open dialogs, field values, scroll and flags. A walk compares the digest forward and back.                    |
| Frame           | The `iframe` that holds a demo's real page.                                                                                                                                |
| Frame shell     | Context around the shown block, such as a terminal window. See [frame shells](/frame-shells).                                                                              |
| Hands-on mode   | Steps stop playing, and your keyboard and pointer reach the demo. Press `h`.                                                                                               |
| Poster          | A still image of one step, written by `live-ish capture`.                                                                                                                  |
| Reader view     | What a shared link shows, at `/` and `/s/<id>`.                                                                                                                            |
| Speaker window  | Your notes, the timer and the controls, at `/speaker`.                                                                                                                     |
| Spotlight       | The highlight that dims a page around one element.                                                                                                                         |
| Stage           | The 1920 by 1080 canvas that holds a slide, scaled to fit the window.                                                                                                      |
| Step            | One press of the clicker. It plays a list of actions in a frame.                                                                                                           |
| Text view       | A slide as plain HTML, for a phone or a screen reader. See the [reader view](/reader-view).                                                                                |
| Underlay        | A poster shown under a frame until the live page is ready, so arrival looks instant and a failed frame still shows something.                                              |
| Walk            | A browser run that drives the deck by key, the way a clicker would. See [verification](/verification).                                                                     |
