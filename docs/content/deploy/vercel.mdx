## Project settings

| ---------------- | ------------------------------------------------------------------------------------- |
| Framework preset | Next.js                                                                               |
| Root directory   | The deck's folder                                                                     |

## The site address

The preset reads `VERCEL_PROJECT_PRODUCTION_URL`, so `hosts.site` is optional. Set it when you use your own domain, in `deck.config.ts` or as `LIVE_ISH_SITE_ORIGIN`.

## What the preset does

- Counts as deployed on a plain `next build`.
- Takes the build id from `VERCEL_GIT_COMMIT_SHA`.
- Sends `Vercel-CDN-Cache-Control` on frame build files. It reaches no browser there, and no other host sends it.
- Keeps a preview out of search. On two hosts, a preview shows posters.

## Two hosts

Add a second domain to the same project, and set `hosts.frames` to it. Both domains serve every route. The origins the presenter uses decide which host shows what, and the frames host answers `Disallow: /` in `robots.txt`.

## Analytics

Off by default. To turn them on, enable them in the Vercel project and set them in `deck.config.ts`.

```ts
analytics: { provider: "vercel", speedInsights: true },
```

No `@vercel/*` package is installed. The scripts load from the addresses the platform serves, on `/` and `/s/<id>` only.
