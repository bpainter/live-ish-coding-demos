A deck has one config file, `deck.config.ts`. It is typed and checked. `schemaVersion`, `title`, `order` and `speaker.name` are required, so four lines start a deck.

```ts
import { defineDeck } from "@live-ish/engine/config";

export default defineDeck({
  schemaVersion: 1,
  title: "Show the code and the result",
  order: ["title", "what-this-shows", "faq", "count-words", "closing"],
  speaker: { name: "Your Name" },
});
```

A wrong field fails with its path, the expected type and the nearest valid name.

## Values worth knowing

| Field                | Default                                                     |
| -------------------- | ----------------------------------------------------------- |
| `lang`               | `"en"`. Drives `<html lang>`, `og:locale` and `inLanguage`. |
| `beats.before`       | `"What we used to do"`                                      |
| `beats.after`        | `"What we can do today"`                                    |
| `theme.extends`      | `"default"`                                                 |
| `theme.grain`        | `true`                                                      |
| `chrome.theme`       | `"glass"`                                                   |
| `presenter.onHost`   | `false`                                                     |
| `reader.enabled`     | `true`                                                      |
| `reader.notes`       | `false`                                                     |
| `reader.index`       | `true`                                                      |
| `analytics.provider` | `"none"`                                                    |
| `writing.preset`     | `"none"`                                                    |
| `checks.fit`         | `"warn"`                                                    |
| `verify.browsers`    | `["chromium"]`                                              |

`speaker`, `event`, `links` and `brand` feed the cover, the closing slide, the metadata and the structured data from one place. An unset field is left out of the structured data, and an unset `event` drops the Event node.

`links.tag` adds query values to outbound links only. Its default adds nothing, so a link is never rewritten without you asking.
