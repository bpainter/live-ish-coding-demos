Present from Chrome or Edge.

## What CI proves

CI runs the browser builds that the pinned Playwright ships, one build of each. Today that is Playwright 1.58.2, with Chromium 145, WebKit 26.0 and Firefox 146. Those versions change only when the Playwright pin moves.

CI runs no branded Chrome, Edge or Safari, and no second version of any browser. The aim is the latest two stable versions of each browser, and only the builds named here have run.

| Surface         | Tested on every pull request | Tested nightly                               | Notes                                                                                |
| --------------- | ---------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------ |
| Audience window | Chromium, WebKit             | WebKit, Firefox                              | Chrome or Edge is the recommendation.                                                |
| Speaker window  | Chromium, WebKit             | WebKit and Firefox, in the drawer check only |                                                                                      |
| Reader view     | Chromium                     | WebKit and Firefox, in the drawer check only | Engine CSS keeps to Baseline widely available, with enhancements behind `@supports`. |
| Text view       | Chromium, at three sizes     | None                                         | Phone sizes with touch on. No real phone.                                            |
| Demo frames     | Your choice                  | Your choice                                  | `verify.browsers` runs a deck's walks where you want them.                           |

WebKit on a pull request means the `hosting` job. The full walks run in WebKit and Firefox at night.

To test the browser you will present from, run a walk in it.

```text
pnpm live-ish walk --channel=chrome
```

## Status today

The nightly column is a target for now. It becomes a promise once the `cross-browser` job is green for 14 nights in a row.

The hosting harness has passed in Chromium 145 and WebKit 26.0, the builds Playwright ships. It covered every step forward and back, keys, a cleared store, and Back and Forward in a multi-page demo.

Firefox has not run that harness. Safari itself has not run it, only WebKit. Mobile browsers have not run it.

## Your demos

The engine's support says nothing about a feature your demo shows. A demo's frame runs in whichever browser you present from, and a feature it needs may be missing there. Run `live-ish support <query>` for real data, and set `verify.browsers` to walk the browsers you plan to use.

```ts
verify: { browsers: ["chromium", "webkit"] },
```

Some features sit behind a flag. Set `verify.chromiumArgs` to launch with it.

## How this changes

A new browser build joins when the Playwright pin moves. Dropping a browser from the pull request column is a breaking change, with a changelog entry.
