Live-ish runs slides and scripted demos of code and UI from one web app. Each click plays one step in a real page and highlights the code behind it.

Live-ish is in preview. The packages are not on npm yet, and the API will change.

## Where to go

- New here: follow the [Quickstart](/start).
- Want to see it first: play the [starter deck](/live) here, with nothing installed.
- Weighing it against another tool: read the [known limits](/limits).
- Met a word you do not know: read the [glossary](/glossary).
- Writing your first demo: read [web demos](/web-demos).
- Presenting soon: read [presenting](/presenting) and the [stage-day checklist](/stage-day).
- Stuck on a finding from `live-ish check`: find its rule under [rules](/errors).
