# file-size

**Fit.** A warning, and an error under `--strict`. `checks.rules` can relax it to `warn` or `off`.

Shown code does not fit the code card. The limit is 44 columns and 40 lines: 44 columns fit the 704 px code card of the 60/40 split at 24 px, so a page can change split freely.

**Fix.** Wrap long lines, or show part of the file with `excerpt()`. The limit follows the layout, so it cannot be raised.
