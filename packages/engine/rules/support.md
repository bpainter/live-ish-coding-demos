# support

**Support.** Runs when a demo uses `support` or an intro. `checks.rules` can set it.

A demo's `support` names an id `web-features` does not have, the feature needs a `fallback`, or `.live-ish/support.json` is out of date.

**Fix.** The message lists close ids. Run `live-ish support <query>` to search the installed data. There is no field for a typed version, by design.
