# image-alt

**Integrity.** Always on, always an error, and it cannot be turned off.

An image has no alt text, or only blank text. This covers a slide's `image`, the `image` on a grid card and the `visual` on a demo's intro. The reader view and screen readers show this text in place of the image.

**Fix.** Set `alt` to what the image shows, in words someone who can't see it can follow.
