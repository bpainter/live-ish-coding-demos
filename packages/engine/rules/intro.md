# intro

**Support.** Runs when a demo uses `support` or an intro. `checks.rules` can set it.

An intro page is incomplete: it has no `support`, its description runs past two sentences or 20 words, it names a number or Baseline, or its still points at something that is not there. A still that has not been captured yet is fine.

**Fix.** Keep the description to what the feature does. Versions and dates come from the support data.
