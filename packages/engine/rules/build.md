# build

**Integrity.** Always on, always an error, and it cannot be turned off.

Something the deck names has no files behind it: an id in `order` with no slide or demo folder, a beat with no `index.html`, a terminal page with no recording, or a server frame whose app has no origin.

**Fix.** The message gives the path it looked in. Add the folder, fix the id, or run `live-ish record <id>` for a terminal demo.
